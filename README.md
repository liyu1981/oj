Prebuilt binaries for project Oj (https://github.com/lovablelabs/oj)
====

This repo is a fork of project Oj with the targetting to provide pre-built binaries of it. So until the upstream starts to provide prebuilt binaries, this repo will

1. keep synced with upstream daily, and
2. if there is a new release tag in upstream, will build the binaries and tag in same tags as upstream

To check the original README of project Oj, please go to: https://github.com/lovablelabs/oj
